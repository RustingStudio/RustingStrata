# Vulkan Backend Implementation Plan

> **For agentic workers:** work task by task, in order. Each task ends with the full suite green on the default model
> and one commit. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a second `Backend` implementation on Vulkan (`ash`, dynamically loaded `libvulkan`), so Strata runs on
non-NVIDIA GPUs, with greedy output identical to CUDA and parity at least 98.5%.

**Architecture:** `src/vulkan/mod.rs` implements `trait Backend`. Every buffer is one `VkBuffer` with one allocation
and a device address, so `Buf.addr` is a real `u64` pointer and the op signatures stay the CUDA ones. Kernels are
GLSL compute shaders in `src/vulkan/shaders/`. They take every pointer as a `uint64_t` push constant through
`GL_EXT_buffer_reference`, so there are no descriptor sets. They are compiled offline with `glslc` into committed
SPIR-V (`src/vulkan/spv/`), which is loaded with `include_bytes!`. Ops are appended to one command buffer that is
submitted at the next host copy or `sync`. `graph` records a reusable command buffer per key.

**Tech Stack:** Rust 2024, `ash` 0.38 (the one approved new crate, with its default `loaded` feature), `glslc`
(shaderc, `/usr/bin/glslc`) at development time only.

**Spec:** `docs/superpowers/specs/2026-10-15-vulkan-and-arch-table-design.md`, Part 3.

  `cpu_worker.rs`, `main.rs`), run a CUDA greedy check (`tools/greedy24.py`) and an interleaved 3-run parity
  control against the previous binary (98.85% default baseline, ±2 tokens per run).

  this machine. Log them as deferred and do not fake them.

  still runs CUDA and the CPU path.
- Every GPU test, bench and parity run goes under `flock /home/vasylt/Code/rusting/.gpu.lock` with the Dota 2 check in
  the same command (see the loop prompt).
- Persisted text is plain English. Commit messages end with the `Co-Authored-By` line.
- Do not edit `README.md`, `LICENSE.md`; `Cargo.toml` only to add `ash`.

## Decisions made here

- **Numerics follow CUDA, not llama.cpp's Vulkan backend.** The integer GEMV quantizes x per 32 values to int8 exactly
  like `quant_x` in `kernels.cu`, and the weights unpack to the same int8 values (`QI<T>`), so every per-32 integer dot
  product is exact and only the float accumulation order differs from CUDA. That is what makes "greedy identical to
  CUDA" a realistic gate.
- **Shared memory is 48 KB on the 3060 under Vulkan** (CUDA opts in to 96 KB). Kernels that need more on CUDA change
  shape on Vulkan: `gemvn` reads x pre-quantized from global memory (a `quant_xq` dispatch first, the same numbers as
  quantizing per block), and `attn_prefill` with head_dim 256 uses 32-query tiles.
- **Subgroup size 32 is required** (`requiredSubgroupSize = 32`, Vulkan 1.3 `subgroupSizeControl`). The 3060 has only
  32. llvmpipe (8) is skipped when picking a device.
- **Push constants at most 128 bytes** (the Vulkan minimum). The largest op, `deltanet`, packs 5 addresses and 10
  32-bit values into 80 bytes.
- **One allocation per buffer** (`ponytail:` about 600 allocations; a sub-allocator if a driver is slow with it).
  Host copies go through one host-visible staging buffer of 64 MB, in chunks.
- **Command flow:** ops append a dispatch and a compute-to-compute memory barrier to the open command buffer. A host
  copy, `sync` or `mem_info` submits it and waits on a fence. `graph(key, f)` records `f` into its own command buffer
  (`SIMULTANEOUS_USE`), runs it, and on later calls submits it again. A pipeline barrier at the start of each command
  buffer orders it after earlier submissions on the queue.
- **Op selection by specialization constant:** one pipeline per (shader, quant type, variant). The GLSL `switch` on the
  type constant replaces the CUDA `QI<T>` / `deq8<T>` templates.
- **Quant tables** (`IQ2XS_GRID` and the rest) go into a generated `src/vulkan/shaders/tables.glsl`. A test renders it
  from `src/quant/tables.rs` and fails if the committed file differs.
- **SPIR-V freshness:** `tools/gen_spirv.sh` compiles every shader. A test runs it into a temp dir when `glslc` is
  installed and fails if a committed `.spv` differs (skips with a note otherwise).
